# 500×500 mm PCB + 30×20 mm FOV 移动相机无缝拼接方案：最终结论

## 1. 结论总览

针对：

- 相机 FOV：30×20 mm
- 被测 PCB / 工件：约 500×500 mm
- 相机通过 XY 运动平台逐 FOV 取图
- 目标：将多个 FOV 组成几何一致、尽量无接缝的 500×500 mm 大图
- 部分 FOV 可能完全空白、没有可用于图像配准的特征
- 生产时允许跳过无需检测的 FOV

最终推荐的核心原则是：

> **不要把“标定结果”设计成固定 FOV 的拼接矩阵；应把标定结果设计成整个 500×500 mm 工作空间上的连续空间几何模型。任意生产 FOV 都根据自己的机台目标位置，从该模型计算自己的最终 Pose/Mosaic Transform。**

因此，**生产 FOV 不需要与标定时的 FOV 一一对应，也不需要使用相同的移动步距。**

---

## 2. 你提出的“纯圆点、无编码大标定板”方案可以成立

标定板可以只有规则小圆点，不一定必须增加二维码、AprilTag、ArUco 或其他编码特征。

前提是已经知道：

- 圆点尺寸
- 圆点 Pitch（X/Y 间距）
- 标定板坐标原点
- 圆点行列关系
- 标定板的平面方向
- 标定板整体几何精度
- 相机 FOV
- 机台脉冲与 mm 的对应关系
- 机台初始零位与标定板之间的已知关系

第一次移动到固定标定板的一个角落后，检测当前 FOV 内圆点，并建立：

```text
(row, column) <-> image point
```

随后，机台每移动一个位置，可以利用机台位置预测当前 FOV 应该看到哪一片圆点，再在当前图像中检测并确认圆点阵列。

因此，不需要给数千甚至上万个圆点逐个编码。

---

## 3. 纯圆点板为什么能知道当前看到的是哪个圆点

不是仅仅依靠：

```text
StagePosition / Pitch
```

直接认定圆点编号。

正确方式是：

### Stage 位置负责“预测”

例如：

```text
Command X = 237.0 mm
Pitch = 5.0 mm
```

只能推断：

```text
当前大约位于 column ≈ 47
```

而不是直接断言：

```text
column = 47
```

### 圆点阵列负责“观测确认”

在预测的局部范围内：

1. 检测圆点
2. 根据圆点间距和行列方向建立局部 lattice
3. 与预计的 `(row, column)` 范围匹配
4. 得到实际观测圆点坐标
5. 由已知圆点坐标反推出真实光学位置

这样即可逐步建立整个工作区域的空间误差模型。

---

## 4. 标定板必须固定不动，而且建议覆盖整个工作区域

对于移动相机、固定标定板的全局 Stage Calibration：

> **标定板应固定在工作台上，不能在标定过程中移动。**

因为目标是测：

```text
Stage Command Position
        ↓
Actual Optical Position
```

整个 500×500 mm 区域的误差。

因此推荐：

- 标定板有效区域至少覆盖 500×500 mm
- 更推荐约 520×520、550×550 mm 等略大于有效工作区的尺寸
- 大板上的圆点应为高精度制造
- 最好提供计量证书或实测坐标/几何精度数据

如果只是写着“Pitch=5 mm”的普通印刷板，而实际圆点位置误差已经大于待补偿的机台误差，则会把：

```text
Stage Error
+
Calibration Plate Error
```

混合起来，导致标定结果不可信。

---

## 5. 光学镜头畸变不需要每个 FOV 单独标定

镜头、相机、倍率和工作距离保持不变时：

> **镜头畸变标定是设备级标定，不是每个生产 FOV 单独标定。**

建立一套：

```text
Camera Intrinsic
Distortion Parameters
Undistortion / Rectification Model
Pixel -> Object Mapping
```

之后所有 FOV 使用同一套光学矫正模型。

只有更换镜头、重新调焦/改倍率、重新安装相机、工作距离明显变化或长期漂移超出验证范围时，才需要重新建立或验证光学标定。

---

## 6. 光学标定板与 Stage 大范围标定板最好分开

### 小型光学标定板

作用：

- Camera Intrinsic
- Lens Distortion
- Pixel Scale
- 局部成像几何

不需要做到 500×500 mm。

### 大型固定圆点板

作用：

- Camera ↔ Stage Transform
- 500×500 mm 全工作区几何标定
- Stage Position Error Map
- Mosaic 全局几何一致性

这两类标定的目标不同，不应混为一谈。

---

## 7. 不应保存“标定 FOV 矩阵列表”

错误设计：

```text
CalibrationMatrix[FOV1]
CalibrationMatrix[FOV2]
CalibrationMatrix[FOV3]
...
```

这种设计会导致一个根本问题：

例如标定时：

```text
C1 = 0 mm
C2 = 25 mm
C3 = 50 mm
```

但生产时：

```text
P1 = 0 mm
P2 = 37.5 mm
```

P2 位于 C2 和 C3 之间，无法直接使用 C2 或 C3 的固定矩阵。

### 正确设计

标定结果应保存成一个连续空间模型：

```text
F(Xcommand, Ycommand)
    ->
{
    ΔX,
    ΔY,
    ΔTheta,
    ...
}
```

或者等价的二维 LUT / 插值误差场：

```text
StageErrorField(X,Y)
```

标定阶段只是对整个误差场进行采样。

---

## 8. 生产时的任意 FOV，都可以通过标定误差场计算自己的 Pose

例如：

```text
Calibration Samples:

C2 = 25 mm
C3 = 50 mm
```

生产：

```text
P2 = 37.5 mm
```

则：

```text
P2 Error
=
Interpolate(
    C2 Error,
    C3 Error
)
```

实际系统中应根据 X/Y 二维位置做二维插值，而不是只做一维插值。

最终：

```text
CommandPose
    ↓
Global Camera/Stage Transform
    ↓
Local Stage Error Field
    ↓
CorrectedPose(P2)
    ↓
MosaicPose(P2)
```

因此：

> **生产 FOV 可以位于任意标定采样位置之间。**

生产移动步距也不要求与标定采样步距一致。

---

## 9. 不要直接插值 3×3 拼接矩阵

不推荐：

```text
Matrix(P2) =
0.5 * Matrix(C2) +
0.5 * Matrix(C3)
```

更正确的是插值几何参数，例如：

```text
ΔX(X,Y)
ΔY(X,Y)
ΔTheta(X,Y)
ScaleX(X,Y)
ScaleY(X,Y)
Shear(X,Y)
```

然后根据生产 Tile 的实际位置重新生成该 Tile 的最终变换矩阵。

---

## 10. Stage Error Map 才是核心标定结果

建议至少建立：

```text
ΔX(X,Y)
ΔY(X,Y)
```

必要时扩展：

```text
ΔTheta(X,Y)
Scale / Orthogonality / Shear
```

整体结构可以定义为：

```text
StageCalibration
├── Global Transform
│   ├── Translation
│   ├── ScaleX
│   ├── ScaleY
│   ├── Rotation
│   └── Orthogonality / Shear
│
├── Local Error Field
│   ├── ΔX(X,Y)
│   ├── ΔY(X,Y)
│   └── 可选 ΔTheta(X,Y)
│
├── Repeatability
├── Bidirectional Error
├── Thermal Drift
└── Validation Statistics
```

如果机台存在明显的方向相关误差、回差或迟滞，则误差模型必要时需要区分运动方向。

---

## 11. 标定采样位置与生产 Tile 位置没有一一对应关系

例如标定：

```text
25 mm × 25 mm sampling grid
```

生产：

```text
22.5 mm × 15 mm tile step
```

仍然可以正常使用。

原因是：

```text
Calibration Grid
=
Spatial Calibration Sampling

Production Tile Grid
=
Actual Acquisition Plan
```

两者职责不同。

标定采样点只是用来描述整个空间误差场。

---

## 12. 最终拼接不能依赖相邻图像一定有特征

由于存在空白 FOV：

```text
FOV A = 有特征
FOV B = 空白
FOV C = 空白
FOV D = 有特征
```

因此绝对不能依赖：

```text
A -> B -> C -> D
```

逐图寻找特征来完成整个拼接。

### 一级定位来源

```text
Stage Corrected Pose
```

### 二级定位来源

当 FOV 有足够纹理并且存在重叠时：

```text
Phase Correlation / FFT-based Translation Refinement
```

或其他高速局部平移配准方法。

因此最终可以：

```text
FinalPose
=
CorrectedStagePose
+
Optional Image Refinement
```

对于完全空白 FOV：

```text
FinalPose
=
CorrectedStagePose
```

仍然有效。

---

## 13. 不建议生产运行时使用 HALCON 角点算法逐 FOV 做定位

你的场景不需要把复杂特征检测作为一级定位机制。

推荐：

### 标定阶段

允许较复杂、较慢的高精度圆点检测和拟合，因为设备安装/维护时执行。

### 生产阶段

主要使用：

```text
Stage Position
        ↓
Calibration Lookup / Interpolation
        ↓
Corrected Tile Pose
```

有可靠图像纹理时，再执行高速局部 refinement。

这样才能兼顾：

- 精度
- 速度
- 空白 FOV
- 稳定性
- 可解释性

---

## 14. “跳过 FOV”不能破坏拼接关系

这是整个系统最重要的软件架构原则之一：

> **Tile 的空间身份必须与图像采集状态分离。**

例如：

```text
Tile 100 -> Image A
Tile 101 -> Image B
Tile 102 -> Skip
Tile 103 -> Image C
Tile 104 -> Image D
```

这里：

- Tile 102 依然存在
- Tile 102 依然有完整 Pose
- 只是没有 Image

绝对不能把：

```text
TileId
```

定义成：

```text
实际拍摄图片的顺序号
```

---

## 15. 应该建立完整 Tile Plan / Tile Pose Map

整个 500×500 mm 工作区在检测开始前，可以建立：

```text
TileId
Row
Column
CommandX
CommandY
CorrectedX
CorrectedY
MosaicPose
Capture / Skip
```

例如：

```text
Tile(17,23)
CommandPose
CorrectedPose
MosaicPose
Capture = true
```

跳过时：

```text
Tile(17,24)
CommandPose
CorrectedPose
MosaicPose
Capture = false
Image = null
```

所以：

> **是否采集图像不会影响这个 Tile 在大图中的空间位置。**

---

## 16. 生产检测可以任意跳图、改变扫描路线

因为 Tile Pose 是由其空间位置独立计算的，所以可以支持：

- 跳过空白区域
- 只拍 PCB ROI
- 只拍缺陷候选区域
- 非连续 Tile 采集
- 改变蛇形/往返扫描路线
- 改变生产 Tile 间距
- 重新选择部分区域进行复拍

都不会破坏全局 Mosaic 坐标。

核心原则：

```text
Spatial Identity != Acquisition Order
```

---

## 18. 最终方案的核心结论

### 结论 1

**500×500 全局 Stage 标定时，应使用固定不动的大型标定板，覆盖整个有效工作区。**

### 结论 2

**标定板不必有编码点。已知规则圆点的尺寸、Pitch、行列关系和起始坐标后，纯圆点板可以工作。**

### 结论 3

**不能单纯用 `StagePosition / Pitch` 直接认定圆点编号。Stage 只负责预测，圆点阵列负责确认和观测。**

### 结论 4

**不要把标定结果保存成“标定 FOV 的固定拼接矩阵”。必须建立整个 500×500 mm 工作区域的连续空间误差模型 `F(X,Y)` / `StageErrorField`。**

### 结论 5

**生产 FOV 可以处于两个标定采样 FOV 之间。根据生产 FOV 自己的 Stage Command 坐标，从误差场插值得到自己的 Corrected Pose，再生成自己的 Mosaic Transform。**

### 结论 6

**因此，标定 FOV 与生产 FOV 不需要一一对应，生产移动步距也不需要等于标定步距。**

### 结论 7

**拼接一级定位必须依赖校正后的 Stage Pose，而不是依赖图像特征。**

### 结论 8

**图像配准只能作为有纹理 FOV 的局部精修；空白 FOV 不参与图像配准，也不会破坏拼接。**

### 结论 9

**跳过 FOV 不会造成拼接矩阵错位，因为 Tile 的空间位置必须预先存在，`Capture/Skip` 只决定有没有图像。**

### 结论 10

最终系统应严格区分三个坐标层次：

```text
Board Coordinate
        ↓
Stage Coordinate
        ↓
Mosaic Coordinate
```

以及两个状态：

```text
Tile Pose
Tile Image
```

其中：

> **Tile Pose 永远独立存在；Tile Image 可以不存在。**

---

## 19. 最终推荐的工程架构一句话总结

> **用固定的大型无编码精密圆点板建立 500×500 mm 连续 Stage 几何误差场；用 Stage 位置预测并确认圆点索引；生产时任何任意位置的 FOV 都通过连续误差场计算自己的 Corrected Pose；有特征时用高速图像配准做局部精修；没有图像或主动跳过的 Tile 仍保留空间 Pose，因此任意跳图都不会破坏最终 Mosaic 坐标体系。**
