Description
copy_image copy_image CopyImage CopyImage copy_image copies the input image into a new image with the
same domain as the input image. In contrast to HALCON operators
such as copy_obj copy_obj CopyObj CopyObj copy_obj , physical copies of all channels are
created. This can be used, for example, to modify the gray values
of the new image (see get_image_pointer1 get_image_pointer1 GetImagePointer1 GetImagePointer1 get_image_pointer1 ).

Multithreading scope: global (may be called from any thread).
Processed without parallelization.
