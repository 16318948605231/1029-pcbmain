# 审计系统自身与发布包可复现性审计
- 文档 ID：`AUD-067`
- 版本：`1.0.0`
- 状态：`PASS_WITH_EXTERNAL_GATES`
- 审计基线：`ARCH-PCBA-VISION-001 v0.5.3` + `Asun Vision Development Standard v2.1.5`
- 范围：除硬件具体 SDK 外的全量开发准备文档、开发步骤、FunctionSpec、PageContract、工具、权威绑定和语义链路

## 1. 审计目标

防止“审计工具本身有盲区”：工具不能读取旧 Registry、旧 Manifest、旧 Master 或旧计数而得到假阳性。

## 2. 工具要求

当前审计器必须直接从活动文档计算：Active Markdown、Unique IDs、FS、PageContract、依赖图、hash、一致性；不能把统计数字写死成通过条件。

## 3. 解压复现

最终 ZIP 在一个干净目录解压后，必须能够运行当前审计器并得到相同的状态类别；工具输出本身写入当前 `10-audit`，旧输出必须在 `98-history`。

## 4. 校验

ZIP test、SHA-256、Registry hash、Master marker 和 Manifest count 都属于发布包验证，不得只验证文件是否存在。
